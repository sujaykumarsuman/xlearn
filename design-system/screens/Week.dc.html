What this week is really about

Most "hard" array problems are just a brute force with one redundant pass removed. This week trains the instinct to collapse nested loops into a single sweep — either two pointers converging on a sorted array, or a window that grows and shrinks while a running condition holds. Learn to recognize which from the problem statement, and the code writes itself.
