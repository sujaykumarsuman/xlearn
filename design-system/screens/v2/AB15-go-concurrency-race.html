AB15 · go-concurrency multi-file + race verdicts

A go-concurrency exercise is a small Go module: some files the learner edits, a public visible_test.go and go.mod they can read. Run executes the visible tests once under the race detector; Submit runs the hidden tests 20× under the race detector (up to 45 s). The runner returns RACE / DEADLOCK / LEAK / WA / TLE / RE / CE; on a timeout it captures a goroutine dump, reduced to your function names and file:line. The hidden tests run inside the learner's program, so every result is honor-grade and left out of judge-checked %. Only the deltas on the frozen AB07★ shell (45:00, hint at 15:00, give-up = Miss, no re-implement) and AB08 dock are drawn.

Withheld. Submit never shows a hidden test's name, source, line or output (TestEvent.Output is dropped). It shows the passed count and the first failure class (R-CT2). Race reports and goroutine dumps are filtered to learner-editable files: a frame in a hidden _test.go, visible_test.go, the standard library or the runtime is collapsed into "+N frames outside your code", never named. Honor. gotest@1 runs the tests in-process, so trust is honor: every result carries "Judge · honor" and is left out of judge-checked % (P7). The HUD says so up front: "honor · tests run in-process".
Verdicts (precedence RACE > DEADLOCK > TLE > LEAK > RE > WA; a missing pass line fails). A race or an assertion failure in any run fails, even if that test passed on other runs. RACE, DEADLOCK, TLE, LEAK, RE and WA are counted failed submits (D18: Clean allows 3). CE and REJECTED are free; inconclusive never counts (INV-14). Limits (t3 §6.2). Run: -race -count=1, job ≤ 20 s. Submit: every declared test -count=20 under -race with goleak, job ≤ 45 s, per-test deadline ≥ 10× the published baseline. Everything else is AB07: one 45:00 server clock, hint at 15:00 caps at Assisted, give-up = Miss, a pass finishes the attempt.

Statement

Build a pool that runs submitted jobs on a fixed number of worker goroutines. At most workers jobs may run at once, Submit must be safe to call from many goroutines, and Wait returns once every submitted job has finished.
