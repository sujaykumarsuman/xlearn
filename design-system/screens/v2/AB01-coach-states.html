AB01 · Coach states

The bring-your-own-key coach under the v2 contract: the D27 per-problem assist confirm and its Assisted cap, the server-side mode gate (attempt · review · general · locked), fail-closed notices, the L18 limits as typed 429s, the cut-short marker, provider errors that never disable a key, the server model catalog, per-feature default keys, and the optional onboarding step. Every string here is final copy; the build copies it verbatim.

Naming reference ADR-0031 §7 · UI names

"Your AI coach (your key)" — the BYO coach. Ships in M1: panel header, FAB label, Settings card, onboarding step. "xLearn AI (included)" — the platform AI. Arrives in M4 (m4-06); it appears on this board only in F14's flagged from M4 variant. FAB aria-label: "Open Your AI coach (your key)"; close button: "Close coach". Never shorten either name to "AI" alone.

A · Mode gate and the D27 assist confirm F1–F7 · m1-07

The panel shows the mode the server decided (gate.mode on GET /api/coach/thread, then X-Coach-Mode on each chat response). The client never gates the coach itself; these frames only report what the gateway returned. Sample context throughout: #16 3Sum (Medium) with an open counted attempt, #1 Two Sum concluded.

State

Trigger

  • POST /api/coach/chat in problem:16's context, attempt open, not yet assisted → 409 assist_confirm_required {error:{code, attemptId, problemId}}. Nothing is sent to the provider, nothing persisted.

Behaviour

  • Ask — cap at Assisted re-sends the same message with assist_ack: <attemptId>. The gateway runs the L18 admission probe, records POST /attempts/{id}/assist (idempotent), then forwards → F3. A 429 from the probe shows F8 and leaves the attempt uncapped; a failed record shows F4.
  • Cancel dismisses the card; the draft stays in the composer; nothing is recorded.
  • Once recorded, later sends and reloads skip this card (the attempt already carries coach_assist_at).
  • Placement: inline in the thread, above the composer — not a page modal, so the problem stays visible.

Decision

  • D27 (per problem): only a chat about this problem during its open counted attempt asks; another page is an accepted, honor-based bypass. D18: coach help ⇒ Assisted. Copy is an honesty prompt, not a claim of detection (t5 §9).

A11y

  • role="alertdialog" labelled by the question. Focus moves to Cancel (drawn with the focus ring): the least consequential action; Tab reaches Ask; Esc = Cancel. Enter in the composer never confirms.
  • Warn border is decorative; the consequence is in text (text 14.2:1, dim 6.8:1).

  • Same card in the sheet; buttons wrap to full width below 360 px (N1).

L18 limits are xLearn's own and come back as typed 429s with Retry-After; they're distinct from the provider's own limits (provider_limited, F10). A rejected request consumes nothing and writes no message.
