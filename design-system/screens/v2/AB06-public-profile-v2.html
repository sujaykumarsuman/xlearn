Header (F1)

  • Identity: display name, @username, the region band (a coarse UTC offset, never the zone) and the joined month. No email, no exact date.
  • Totals from visible courses only (D7, P6): Solved = passed core items summed by the gateway; Current / longest streak and the Activity heatmap from proj_activity (attempts + reviews + mocks per UTC day); Mock interviews · 6 is a count (D31) — v1's "Mock best · Avg" tile is gone.
  • Heatmap cells read "Sep 21: 3 activities" (date only). The anonymous header offers Sign in; a signed-in viewer sees the app's plain top bar (v1 behaviour).

Course rows (F3, F4 in place)

  • One row per course that is enrolled ∩ visible ∩ active (P2; preview never appears, ADR-0034 §2). First row open, the rest collapsed (v1). Collapsed: title + "Concluded · Passed · of N core" + meter of passed.
  • Expanded: difficulty split (passed / total per difficulty token), judge-checked, reviews completed + Day-7 pass rate (P9), mock count, the first-attempt grade mix with provenance (P7), completion by phase and topic mastery (v1's roll-ups).
