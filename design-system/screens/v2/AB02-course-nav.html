Rules (v1 buildCrumbs, now for any course)

  • /:course/week/:n → xlearn / <course> / week/N.
  • /:course/concept/:slug → xlearn / <course> / [week N /] concept/slug; "week N" only from a numeric ?week= and links to that week.
  • /:course/problem/:id → xlearn / <course> / problems / #id; "problems" links to the Problems arena (no singular index).
  • Anything else: one crumb per segment; the last is the current page (bold, not a link). xlearn links to the Catalog unless it's the only crumb.

Parity

  • DSA trails are character-identical to v1 (m1-03 snapshot tests). Crumbs show the slug, not the title (v1).
  • The last row shows the same rules on a second course; the item segment stays problem/problems in URLs for every course (t0 §7: same segments), while nav labels can differ (F8).

A11y

  • Mono 12.5 px; links dim 7.7:1, current page text 16:1, separators decorative. Markup unchanged from v1 (a plain div.xl-crumb).
