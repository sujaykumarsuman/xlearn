What changes vs v1

  • Pattern withheld: every due row shows xl-lock "Pattern hidden while due" where v1 showed the xl-pat chip (Revision.tsx:235-237). The due payload carries no pattern: the server strips it (m1-06 withhold(), lists: live(s)). The lock is not a hidden value — there's nothing in the DOM to reveal.
  • Format badge per row from the manifest band for its touchLevel (rule strip above). L4–5 keep v1's violet mock badge and dashed mock dot.
  • Scope toggle "This course · All courses" (F8); course-scoped by default. Built in p-02; m1-06 omits the control until then.
  • Everything else is v1 copy and layout: banner, group heads, touch dots, notes, buttons, right rail.

Coming up (not due)

  • A row that isn't due and whose item has concluded with a pass keeps v1's pattern chip: nothing is live (ADR-0027 §1; t4 §6.4 withholds only while live).
  • Conservative reading for M2 (R-SR1, a Miss also gets a ladder): a never-solved item keeps the lock on every row until it's solved.

Decision · a11y · narrow

  • R-SR2 (touch format per band), ADR-0027 §1 / t4 §6.4 (withhold while due; fixes the leaking chip), D3.
  • The lock reads as text ("Pattern hidden while due"); its muted colour is a theme debt (3.4:1), so the meaning is also in the group head ("Due · …"). Badge text 7.4:1. Focus order per card: title link → Re-solve from blank.
  • < 1024 px: the right rail drops below the queue; rows become full-width cards (F9).
