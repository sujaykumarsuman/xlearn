Board-wide rules D10 · D17 · ADR-0027 §4 · t4 §4.4

Nothing here counts (D10). The arena context id is uuidv5(account, item), derived server-side (judge ignores any client value; the SPA never sends one). Runs aren't persisted — samples and custom input only, with no reference oracle for custom input. Arena submits are persisted (History, F4) and are learner-private in v2.0: they never reach /public/stats (P10 allowlist). No arena event is ever emitted; no practice call, attempt, timer, grade, revision or mistake comes from here. The only state the arena changes is its own marker (arena_progress) and, once, the reveal record (F6). The arena runs code steps only (t4 §4.4): a key or ai_rubric step shows AB08-F13's "Checked only in a course attempt or review."; quiz and canvas items open in study mode (F8).
Unrestricted (D17). There is no lock state on this board. Run, Submit, History, Copy to editor, Diff and Solution work during an open course attempt and during a due or live review. t4 §3.7 / §8's "Finish your review first" locks and its "caps your course attempt at Assisted" confirm are superseded (t4 §13, PRD R-AR1 amended) and are not drawn. Withheld ≠ locked. What withhold() strips on every surface while an item is live — the pattern chip, concept chips, the hint stage — is simply absent here, never drawn as a lock (ADR-0027 §1 nudge). The Solution is the one stage behind a question (F6), and answering it is recorded, never capped. Copy is AB08's. Verdict lines, limit lines and history rows are AB08's strings, verbatim; "arena" is added only to the quota line, as AB08-F15 already does.
A11y on every frame. Text --ds-text 15:1 and --ds-dim 7.2:1 on the panels; --ds-muted only for non-essential meta; badge and chip text ≥ 5.5:1 on its tint. Every tone travels with a word or an icon, never colour alone. The drawn focus ring (bd-focus, the app's :focus-visible) marks where focus lands first in a frame; each frame's notes give its focus order. Status changes are aria-live="polite"; nothing steals focus; ds-spin becomes a static icon under reduced motion.
