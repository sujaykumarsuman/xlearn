A monotonic stack keeps its elements in sorted order (increasing or decreasing) by popping anything that would break the order before pushing the new element. The moment you pop an element, the element about to be pushed is its 'next greater/smaller' neighbour — so a single left-to-right pass answers next-greater-element, daily-temperatures, and histogram-area questions in O(n) total, since each index is pushed and popped at most once.
