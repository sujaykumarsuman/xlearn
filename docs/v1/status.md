The gateway composes the taxonomy: `GET /progress` **agg** joins the projections with a new curriculum bulk read `GET /paths/{slug}/problems` for the by-phase completion + by-pattern mastery; `GET /dashboard` **agg** fans out **in parallel** (per-call timeouts) to assessment + review + curriculum (+ a practice week-state call), composing "Today" with **due reviews ahead of new problems** (R-SR5). The **Progress** screen (4 tiles, teal heatmap, completion-by-phase, mastery bars, rubric trend vs W13/W15/pre, outcome mix) and the finalized **Dashboard ★** (quick stats, plan, week-progress bar, five-touch revisions-due panel, weak-area card) are built + verified in-browser vs the artboards.
